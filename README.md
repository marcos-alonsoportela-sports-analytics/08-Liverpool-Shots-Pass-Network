# Liverpool — Shot Locations & Passing Network Analysis

Analysis of Liverpool's shooting zones and passing network using StatsBomb event data.

## Overview

This project analyses Liverpool's attacking behaviour using event-based football data.

The analysis combines two complementary perspectives:

- Shot location analysis.
- Passing network analysis.

The objective is to explore both the spatial distribution of Liverpool's shooting actions and the team's passing structure.

## Objectives

- Analyse the spatial distribution of Liverpool's shots.
- Identify areas from which shooting actions are generated.
- Build and visualise Liverpool's passing network.
- Explore connections and involvement between players.
- Apply event-data analysis to team tactical behaviour.

## Methodology

The analysis includes:

1. Loading and preparing event data.
2. Filtering Liverpool's actions.
3. Analysing shot locations on the pitch.
4. Building the team's passing network.
5. Calculating and visualising passing connections.
6. Interpreting the resulting attacking patterns.

## Tools

- Python
- Pandas
- Matplotlib
- mplsoccer
- StatsBomb event data
- Jupyter Notebook

## Data

The analysis uses StatsBomb event data.

Match/event identifier:

`event_id = 22912`

## Output

The project produces visualisations representing:

- Liverpool's shooting locations.
- The team's passing network.
- Spatial and relational patterns in Liverpool's attacking play.
